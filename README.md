# HowToLiveBetter 独立核验知识库

> 对 `eternity4719/HowToLiveBetter` 的 **552 条建议逐条独立审计版**。  
> 当前状态：**552 / 552 已完成第一轮核验**。  
> 最后核验日期：**2026-09-20**。

## 30 秒看懂这个仓库

原知识库有很多高质量来源，但它的 **A / B / C 并不能直接当成“可信度等级”**。

最核心的问题是：

> **来源真实 ≠ 因果成立 ≠ 可以直接写成行动处方。**

例如，一篇真实的大型队列研究可以证明“某行为和更低死亡率相关”，但不能自动证明“照着做就一定把死亡率降这么多”。

因此，本仓库重新检查了 552 条内容的：

- 来源是否真实存在；
- DOI、PubMed、官方文件是否对应得上；
- 论文到底是 RCT、Meta、队列还是病例对照；
- 原文数字有没有抄错；
- 相关性有没有被写成因果；
- 研究人群有没有被过度外推；
- 法律、医保、税务、签证、教育政策是否已经更新；
- 是否存在争议、更新证据或明显过时内容。

## 核验结果怎么看

| 标记 | 含义 |
|---|---|
| ✅ | 核心结论可信，来源与表述基本匹配 |
| 🟡 | 基本可信，但需要限定人群、因果强度或适用场景 |
| 🟠 | 证据不足、来源映射不完整，或仍有关键内容待核实 |
| 🔵 | 有明显争议，不能按单一结论使用 |
| 🔴 | 明显错误、已过时，或当前规则已发生变化 |
| ⚪ | 主要是经验建议，缺乏直接可量化证据 |

> 原作者的 A/B/C 仍然保留在审计表中，但只作为“原始等级”，**不会作为本仓库最终判断**。

## 最值得先看的结果

### 1. 很多“健康收益数字”是真的，但不是因果

比较典型的包括：

- 每天 7000–8000 步；
- 茶、咖啡、坚果；
- 辣椒、奶制品；
- 泡澡；
- 绿地；
- 社会关系；
- 睡眠时长；
- 久坐与死亡率。

这些研究往往是真实的大型队列或 Meta，但多数属于 **观察性研究**。

因此正确读法通常是：

> “这种行为和更低风险有关。”

而不是：

> “只要照着做，就会获得论文里同样幅度的风险下降。”

---

### 2. 有些 A 级证据非常强

例如：

- 低钠盐随机对照试验；
- 高血压降压治疗；
- 跌倒预防运动；
- 带状疱疹疫苗；
- 部分癌症筛查；
- 低剂量 CT 肺癌筛查；
- 婴儿安全睡眠；
- 叶酸预防神经管缺陷；
- 心肺复苏 / AED；
- 狂犬病暴露后处理。

但即使是强证据，也必须看 **研究对象是不是你**。

例如低钠盐的强 RCT 主要来自老年、高血压或既往卒中等高风险人群，不能把同样效果数字直接套到所有健康年轻人。

---

### 3. 明确发现了一批需要修正的内容

本次审计中，以下类型问题已经被明确标红、降级或重写：

- **“珠宝玉石只认 CMA 报告”**  
  2026 年“一单一库”制度实施后，这个说法已经不能绝对成立。

- **“居民医保全国都是 400 元/年”**  
  错。很多地区是 400 元，但并非全国统一。

- **“野外水高海拔也不用多煮”**  
  过度绝对，高海拔条件下煮沸时间需要调整。

- **“熊、野猪、野狗都用同一套退避方式”**  
  错。不同动物的应对原则不能混在一起。

- **“破水后一律平躺、垫高臀部、不走动”**  
  不是普遍产科指南，应按胎位、脐带脱垂风险和产科建议判断。

- **“跨省异地就医原则上必须副主任医师以上评估”**  
  不是全国统一前置条件。

- **“基层服务项目每年固定 10% 定向考录”**  
  不能作为长期固定政策使用。

- **“休学最长 1 年”**  
  不是全国统一学籍规则。

- **“两年内寿险自杀一律不赔”**  
  法律表述不完整，实际还存在法定例外及现金价值处理。

- **美国 F-1 2026 新规**  
  固定停留期规则已经改变，但存在过渡安排，不能只写成“最长四年、毕业后 30 天离境”。

## 原库与本仓库的区别

原库当前正文实际包含：

- **总计：552 条**
- A：366 条
- B：136 条
- C：50 条

原库 README 仍显示旧统计 **498 条**，因此本仓库以正文实际抽取结果为准。

本仓库不会简单说：

> “A 就可信，B 次之，C 最差。”

因为：

- A 里可能是 RCT；
- 也可能是观察性队列；
- 也可能只是法律法规；
- 也可能是官方政策；
- 甚至可能存在过时政策。

所以本仓库把“证据等级”拆成多个维度重新看。

---

## 审计边界

这里的“552 / 552 已完成第一轮核验”表示：

- 每条都检查了来源结构；
- 检查了研究或法规类型；
- 检查了标题与来源是否匹配；
- 检查了明显的因果误读和人群外推；
- 动态政策优先检查现行官方规则；
- 有 TODO 或关键来源缺失的条目会明确标记“部分待核实”。

但这 **不等于**：

- 对每篇论文都做了全文级系统综述；
- 对所有国家、所有省市的地方细则都穷尽核验；
- 这些结论以后永远不会过时。

法律、医保、税务、签证、招生、平台监管这类内容尤其需要定期复审。

## 推荐使用方式

如果你只是想快速判断某条建议能不能信：

1. 在 `data/audit-index.csv` 搜标题；
2. 看 `audit_status`；
3. 再打开对应章节看核验摘要；
4. 遇到 🟡 / 🟠 / 🔵 / 🔴 时，不要只看原标题；
5. 涉及法律、医保、税务、签证、招生时，再确认 `last_verified` 日期。

如果你要把本仓库接入 AI / Agent / 个人知识库，建议优先保留：

`original_grade`、`audit_status`、`study_design`、`source_status`、`numeric_check`、`causal_strength`、`population_match`、`last_verified`、`superseded_by`。
